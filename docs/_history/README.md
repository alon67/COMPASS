# Superseded audit responses

These are the responses to earlier review rounds, kept because the record of how
this project answered each audit is part of its evidence. **They support no
current number.** Every claim in them is superseded by
`docs/COMPASS_AUDIT_RESPONSE_4_2026-08-09.md` and by the artifacts that response
cites, which were regenerated under measurement schema `probe-4`.

They are deliberately **not edited** to satisfy checks introduced after they were
written. `tools/verify_report_numbers.py` enforces a set of forbidden phrasings
that has grown with each round; retro-fitting a historical document to today's
rules would misrepresent what was said at the time, which is the opposite of why
the record is kept. The verifier therefore reads `docs/COMPASS_AUDIT_RESPONSE_*.md`
— the current response — and this directory is outside its scope, on the same
principle as `data/provenance/_history/`.

The audits themselves stay at the repository root: they are inputs the project
received, not outputs it produced.
