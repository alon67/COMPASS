# COMPASS model audit

Canonical-reproduction audit for every model in the panel (blueprint WP1, §6.2/6.3).

A model is included only if it executes reproducibly under a pinned simulator, has named mechanisms and a documented morphology or explicit point-model designation, reproduces the qualitative and (where stated) quantitative behaviour of its source, **and** runs its production campaign at a time step and mesh that its own feature-level convergence audit accepts. Every deviation found is recorded here rather than corrected silently.

Numerical evidence is read from `data/provenance/convergence_audit_<model>.json`, the feature-level audit over prior samples. The older `numerical_qc.json` judged a single canonical point on spike count alone and is retained only as history; it is not consulted here.

Counting convention: **sections** are morphological compartments as the published source defines them; **segments** (`nseg`) are the numerical discretisation COMPASS runs, which is a solver choice and not a biological quantity; voltage is recorded at one somatic segment.

Generated by `tools/build_model_audit.py` from `results/manifests/canonical_*.json` and `data/provenance/`.

## Deviations and declared limitations

1. **`migliore_ca1` spatial discretisation.** The as-distributed mesh (559 segments) is not spatially converged: a 0.5 nA step gives 5 spikes there but 6 on both the d_lambda(100 Hz) mesh and a mesh twice as fine. The model is run on the d_lambda(100 Hz) mesh (1106 segments).
2. **`migliore_ca1` time step.** The feature-level convergence audit accepts dt = 0.025 ms at every audited point, and that is what the campaign runs. (The superseded `numerical_qc.json` rejected 0.025 ms on an exact spike-count comparison at a single canonical point sitting on a 4-versus-5-spike knife edge; that record is history, not evidence.)
3. **`migliore_ca1` initial state.** The published model pins V_rest by solving `e_pas(x) = v(x) + (ina(x)+ik(x))/g_pas(x)` after `finitialize`. This is reproduced (`MiglioreCA1._post_finitialize`) and re-run for every parameter sample; without it the cell rests near -75 mV instead of -65 mV.
4. **Spontaneously active models** (`khaliq_purkinje`, `moubarak_snc_da`) have rheobase 0, so the rheobase-normalised protocol family is undefined for them. Reported as a coverage limitation, not imputed.
5. **`bbp_l5pc` axon is passive** in `L5PCbiophys3.hoc` (leak only), so no axonal conductance is sampled for this model.
6. **`ortner_snc_da` partial protocol coverage.** Its maximum firing rate over the tested range is ~7.5 Hz, i.e. three spikes in the frozen 400 ms analysis window, so ISI-derived features sit at their definitional floor. It is reported in a labelled partial-coverage stratum and excluded from primary cross-model inference.
7. **`ortner_snc_da` and `dougalis_vlpag_da` share a code lineage.** Both NEURON implementations name the same author and reuse the same `A.mod` / `H.mod`, so they are recorded as two implementations of `dougalis_2017`, not as two independent lineages.
8. **`tomko_ca1` shares the Migliore mechanism lineage.** Morphology and optimisation are independent (Cutsuridis geometry, BluePyOpt against HippoUnit) but the channel kinetics come from Migliore et al. 2018, so it is a nested implementation of `migliore_1999`.
