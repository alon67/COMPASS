## Deviations and declared limitations

1. **`migliore_ca1` spatial discretisation.** The as-distributed mesh (559 segments) is not spatially converged: a 0.5 nA step gives 5 spikes there but 6 on both the d_lambda(100 Hz) mesh and a mesh twice as fine. The model is run on the d_lambda(100 Hz) mesh (1106 segments).
2. **`migliore_ca1` time step.** The convergence audit accepts only dt = 0.0125 ms; the campaign runs 0.025 ms because 0.0125 ms would cost more wall time than the other seven models combined. Identical for every sample, so within-model dependence structure is unaffected.
3. **`migliore_ca1` initial state.** The published model pins V_rest by solving `e_pas(x) = v(x) + (ina(x)+ik(x))/g_pas(x)` after `finitialize`. This is reproduced (`MiglioreCA1._post_finitialize`) and re-run for every parameter sample; without it the cell rests near -75 mV instead of -65 mV.
4. **`khaliq_purkinje` is spontaneously active**, so its rheobase is 0 and the rheobase-normalised protocol family is undefined for it. Reported as a coverage limitation, not imputed.
5. **`bbp_l5pc` axon is passive** in `L5PCbiophys3.hoc` (leak only), so no axonal conductance is sampled for this model.
